## 1. 一句话定位

> 每天一篇刚好比你水平难一点（i+1）的英文文章，阅读时随手标生词，
> 第二天用间隔重复把它吃掉。

不是“又一个背单词软件”，而是**以每日阅读为入口的词汇学习闭环**。
成功标准不是功能数量，而是**每日闭环能在 5 分钟内走完**：
打开 → 读一篇 → 标几个词 → 复习完 → 关掉。

## 2. 目标用户

- 第一版只服务作者本人：Windows 桌面、有 OpenAI 兼容 API Key、
  想稳定提升词汇量与阅读能力；
- 不需要账号、社交、排行榜、打卡分享；
- 接受本地单机运行，数据只存在本机。

## 3. 核心闭环

```
首次启动                                  每天
┌───────────────────────────┐        ┌────────────────────────────────┐
│ ① 配置 AI                 │        │ 打开 → 今日文章（当天已缓存）   │
│   base_url / key / model  │        │  → 阅读，双击单词看语境释义     │
│ ② 真实连接测试（必须通过） │ ───→   │  → 加入生词本（正文高亮）       │
│ ③ 摸底测评 or 手动选级     │        │  → 阅读完成：答几道题，AI 调级   │
│                           │        │  → 复习今天到期的词（3~5 分钟） │
│ ④ 进入首页                 │        │  → 连续天数 +1                  │
└───────────────────────────┘        └────────────────────────────────┘
```

关键产品约束（用户明确提出）：

1. 第一次进入必须先配置模型地址、Key、模型 id；
2. **连接成功后才能进入下一步**，不能跳过；
3. 之后根据用户水平每天推荐一篇文章；
4. 阅读时可以标注生僻词，进入生词本并参与复习。

## 4. MVP 功能（P0）

| 模块 | 做什么 | 验收标准 |
|---|---|---|
| 配置向导 | 服务地址、Key、模型 id、温度；预设常见服务商 | 连接失败给出具体原因，不允许进入下一步 |
| 水平测评 | 固定题库短文 + 理解题 + 词汇题 + 英译中题，AI 只负责评分 | 输出 CEFR（A2~C1）+ 词汇量估算 + 薄弱点；允许手动覆盖；选择题必答，不会可点「不知道」，并可在题目下写一句哪里看不懂交给 AI 参考 |
| 每日文章 | 按等级与兴趣生成 250~350 词；当天缓存 | 结构化 JSON；本地校验；失败重试一次；可“换一篇” |
| 阅读器 | 排版、字号/行距；双击单词弹出释义卡 | 音标、词性、语境义、英文释义、例句；一键入生词本并高亮 |
| 阅读检测 | 两轮自适应：先 3 道当前等级题，再按表现出 2 道边界题 + 2 道英译中题；AI 讲评 + 盲评，本地后验调级 | 题库分阶段缓存；本地判分；每题题型/难度/错因；英译中按理解准确给 0/1；题目审核；选项随机；盲评不看当前等级；置信度 ≥ 0.6 才建议改级；升级连续两次；同一天只一次正式检测；支持最大化 / F11 全屏；失败可重试且不改画像 |
| 每周复盘 | 汇总本周检测、生词、复习数据，AI 给出趋势与下周重点 | 同一周缓存；AI 只建议；用户确认后才改等级；无数据时不调用 AI |
| 生词本 | 列表、筛选、编辑释义、删除、记忆方法 | 双击只查词，点“加入生词本”才入本；按词典原形合并，记录文章词形；AI 记忆方法可查看/重新生成 |
| 复习 | 简化 SM-2，四档反馈（支持拼写回忆与本地判分），忘记/模糊求助 | 只出到期词；离线可用；复习历史落库；拼写判分只给建议、不改调度；AI 建议可跳过 |
| 首页 | 连续天数、待复习数、累计生词、今日文章状态 | 数据从 SQLite 读取，AI 不可用时仍可打开 |
| 设置 | 查看/修改 AI 配置、测试连接、AI 用量与日志、数据导出 | Key 脱敏；配置目录可打开；调用记录只存 token/耗时/错误，不存提示词与回复 |

## 5. 明确不做（V2+）

- 口语对话陪练、语音识别与发音评分；
- TTS 朗读；
- 真实外刊/RSS 抓取（V1 用 AI 生成文章，见决策 1）；
- 云同步、多用户、账号体系；
- Anki 导入导出、移动端。

## 6. 已确认的产品决策

| # | 决策 | 理由 |
|---|---|---|
| 1 | **V1 文章由 AI 生成，不抓真实外刊** | 难度可控；可刻意复现生词本里到期的词；无版权、反爬、断网问题。V2 再引入真实内容源 |
| 2 | **测评用固定题库 + AI 评分**，不让 AI 自由出题 | 结果可复现、可比较；AI 只做主观题评分 |
| 3 | SRS 用**简化 SM-2**，四档反馈 | 实现简单、可解释；以后换 FSRS 只改 `services/srs.py` |
| 4 | **中文界面**，学习材料英文 | 用户是中文母语者；释义给中英双语 |
| 5 | **V1 只用单模型，不做双模型槽位 / 成本路由**（2026-11-20 修订） | 个人使用、调用量可控，成本不是瓶颈；多模型配置的复杂度不划算，查词延迟明显时再单独评估 |
| 6 | 首次配置**强制真实请求测试** | 挡掉“配错了以为程序坏了”的大部分问题 |
| 7 | 使用 **OpenAI 兼容协议 + 自定义 base_url** | 一套代码通吃 DeepSeek/Kimi/通义/智谱/硅基流动/OpenRouter/Ollama |
| 8 | 每天默认 **1 篇文章** | 保证闭环成本；后续可配置 |
| 9 | 阅读检测由 **AI 按当天文章出题 + 本地判分 + AI 讲评调级** | 题目贴合原文、判分可解释；等级变化有硬约束，避免一次答题跨级 |
| 10 | 等级升级采用**连续证据**：两次向上信号才生效，降级立即生效 | 单次检测噪声大；升级慢一点更稳，读得吃力时先降难度保护体验 |

## 7. 信息架构

| 页面 | 内容 |
|---|---|
| 今日 | 连续天数、待复习、累计生词、今日文章卡、今日复习卡 |
| 阅读 | 正文全宽阅读器 + 双击弹悬浮释义卡 + 阅读完成检测弹窗 |
| 生词本 | 词条列表、筛选、编辑 |
| 复习 | 卡片式复习队列 |
| 设置 | AI 配置、数据与安全、关于 |

首次启动额外有：AI 配置向导（3 步）→ 水平测评（可跳过，手动选级）。

## 8. 数据与隐私

- 配置目录（仓库外）：
  - Windows `%APPDATA%\EnglishLearner\`
  - macOS `~/Library/Application Support/EnglishLearner/`
  - Linux `~/.config/english_learner/`
- API Key 在 Windows 上用系统 DPAPI 加密后写入 `config.json`（与当前用户绑定）；
  非 Windows 或加密失败时回退明文并收紧文件权限。
- 学习数据保存为同目录下 SQLite `data.db`；设置页可导出 JSON / CSV 备份。
- AI 调用记录（任务、模型、token 用量、耗时、错误分类）保存在 `ai_calls` 表，
  **不保存提示词与模型回复正文**；设置页可查看今日/累计用量与明细并清空。
- 只有调用 AI 时，才把当前文章/单词/答题内容发给用户配置的服务商。

## 10. 主要风险与对策

| 风险 | 对策 |
|---|---|
| AI 生成文章质量飘 | 严格 JSON 契约 + 本地校验 + 重试 + “换一篇”；prompt 模板版本化 |
| 查词释义不准 | 传上下文句子要“语境义”；展示英文释义与例句；允许手动改 |
| token 费用失控 | 释义与文章落库缓存；一天一篇；单模型即可（个人使用，不做成本路由） |
| 等级判断不可靠 | 固定题库 + 手动作答；AI 只评分；允许手动覆盖等级 |
| 坚持不下去 | 5 分钟闭环；离线可复习；不做社交压力 |
| 用户配置的服务商不兼容 | 连接测试快速失败 + 中文错误提示；预设常见服务商 |
